# 校园导览 App · 功能拆解与版本规划

> 产品定位：为四川文轩职业学院遂宁校区的**新生、在校生、教职工与访客**提供
> 校内外一体化的找地点、步行导航与校园信息服务。
> 形态：零后端纯静态 Web App（PWA），手机浏览器/添加到主屏幕即用，可离线。

## V3.2 — P1 近期（不需要后端，纯前端可加）

- **热门地点快捷入口**：地图底部横向 chips（食堂/快递/运动场/医务室）一键定位
- **地点照片**：每栋楼 1-2 张实拍（需拍摄收集，存 assets/）
- **夜间模式**：底图滤镜 + 界面暗色变量
- **分享**：地点详情生成链接/海报（Web Share API）
- **双语标注**：建筑名中英对照（需要校方提供官方译名）
- **数据纠错**：地点详情内「报错」入口，生成预填反馈

## V4 — P2 中期（需要校方配合 / 轻后端）

- **室内楼层图**：图书馆/教学楼逐层平面（需校方提供 CAD/图纸），
  技术上沿用本工程：每层一张图 + `L.imageOverlay` + 楼层切换器
- **室内定位**：MVP 用「楼层选择 + 二维码扫码定位」（零硬件成本）；
  精度需求上来后部署蓝牙 iBeacon（1-3m 精度，信标几十元/个）
- **课表/考试对接**：对接教务系统或以「导入课表」方式解析上课地点，一键导航教室
- **校园活动地图**：活动数据从静态 JSON 起步，后期接后台
- **校车/摆渡车**：路线、站点、时刻表图层
- **失物招领/地点点评**：需要轻后端（云函数 + 数据库即可起步）
- **好友位置共享**：需要账号体系与实时通道，隐私合规要求高

## 技术说明

- **为什么不用高德/百度 SDK**：通用地图在校园尺度信息密度不足，且无法使用官方手绘导视图。
  当前方案（自绘平面坐标系 + Leaflet）完全掌控数据，零 API Key、零费用、可离线。
- **数据维护**：POI 集中在 `js/campus-data.js` 一个文件，改坐标/加地点即改数据，
  无需数据库；后续若接后台，此文件结构可直接映射为数据库表。
- **离线**：Service Worker 预缓存全部核心资产，首次打开后断网可用。
- **隐私合规**：无账号、无上传、无追踪；位置数据仅本机，协议中已明确。
