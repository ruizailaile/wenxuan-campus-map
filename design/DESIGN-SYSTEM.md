# 文轩遂宁校区地图 · 液态玻璃设计系统
> 术语库 → 模版墙 → 设计规范，三模块对应「说不清 → 没灵感 → 做不对」。
> 令牌逆向自线上代码（css/style.css v3.8），与实际渲染 1:1 对应。
> 机器可读版：[design-tokens.json](./design-tokens.json)

## 一、术语库 —— 把"感觉"翻译成设计语言

对 AI 说左边的话，应自动匹配右边的技术实现：

### 材质类
| 用户说 | 技术术语 | 实现参数 |
|--------|----------|----------|
| "玻璃质感""高级""通透" | 液态玻璃 L1 面板 | `rgba(255,255,255,.68)` + `blur(40px) saturate(200%)` + 渐变描边 |
| "轻一点的玻璃" | 液态玻璃 L2 控件 | `rgba(255,255,255,.55)` + `blur(28px) saturate(180%)` |
| "要有边缘反光" | 渐变边缘光（签名①） | 1.5px `--edge-glow` 白金渐变 + mask 抠边 |
| "看起来像真玻璃" | 镜面高光（签名②） | `inset 0 1px 0 rgba(255,255,255,.85)` |
| "要有悬浮感" | 环境光晕投影（签名③） | 三件套阴影（见规范·阴影） |
| "背后要透出颜色" | 极光背景层 L0 | 5 组径向光斑 + `aurora-drift 36s` 漂移 |
| "深色模式别看不清" | 深色玻璃 | `rgba(34,36,62,.86)`，底图 `brightness(.78)` |

### 交互类
| 用户说 | 技术术语 | 实现参数 |
|--------|----------|----------|
| "能拖、有手感" | 阻尼拖拽 | 上拖 ×0.4 / 下拖 ×0.85（`sheetDamping`） |
| "松手自动停靠" | 吸附停靠 | 速度>0.65px/ms 甩动判定；位置阈值见令牌 `motion.sheetSnap` |
| "弹回来一点" | 弹簧回弹 | `cubic-bezier(0.34,1.56,0.64,1)` |
| "长按出菜单" | 锚定浮动气泡 | 480ms 触发，`translate(-50%,-100%)` + 指向箭头 |
| "展开成整页" | 卡片展开全屏 | 抽屉 `sheet-full` 态：height 100vh、圆角→0 |
| "按一下有反馈" | 按压缩放 | `scale(0.96)` + `160ms` |
| "抖一下" | 触觉反馈 | `navigator.vibrate(10~12)` |

### 布局类
| 用户说 | 技术术语 | 实现参数 |
|--------|----------|----------|
| "底部弹窗""半屏" | 底部抽屉 peek 态 | `max-height: 86vh`、顶角 26px |
| "贴边""全面屏安全" | 底部安全区 | `calc(24px + env(safe-area-inset-bottom))` |
| "拇指够得着" | 拇指热区 | 主操作置于底部 30% 区域 |
| "别被 Tab 挡住" | 层级深度 | 弹窗 2000 < 编辑 2100 < 气泡 2600 < 提示 3000 |

## 二、模版墙 —— 六套场景预设

每个模版 = 材质 + 圆角 + 阴影 + 动效的打包预设，直接点名使用。

### T1 · 地图主界面「液态玻璃 + 插画风底图」
- 底图：卡通风渲染图 + 深色模式 `brightness(.78) saturate(.92)`
- 悬浮控件（搜索框/图例/Tab 栏）：L2 玻璃、`radius: pill`、`--shadow-glass`
- POI 标记：CSS 变量 `--c: 分类色` 驱动圆点+名称芯片，选中态扩散光环脉冲

### T2 · 底部抽屉（建筑详情 / 已实现 v3.8）
- 顶角 `26px 26px 0 0`、`max-height 86vh`、手柄 `44×5px` 圆条
- 弹出 `sheetUp .4s spring`；吸附/回弹 `cubic-bezier(.32,1.3,.36,1)`
- 全屏态：直角、`height 100vh`、内容滚动 `overscroll-behavior: contain`

### T3 · 锚定气泡（长按快捷菜单 / 已实现 v3.8）
- `radius 16px`、`min-width 168px`、菜单项 `11px 12px` 圆角 11px
- 弹出 `popIn .28s spring`（scale .82→1，方向朝锚点），消失 `popOut .16s`
- 靠顶自动翻转到锚点下方（`.below`），箭头同步翻转

### T4 · 玻璃卡片组（个人中心/列表）
- 分组容器：L1 玻璃 `radius 22px`；列表项：`radius 14px`、按压 `rgba(accent,.07)`
- 拖拽态（v3.8）：`scale(1.05)` + 深阴影 + z-index 提升

### T5 · 发光路径 + 流动粒子（路线导航）
- 路线：分类色加粗描边 + 发光外晕；转向提示用弹簧曲线依次浮现
- 步行时长芯片：L2 玻璃胶囊，数字用 `tabular-nums`

### T6 · 多步骤表单（失物招领预留）
- 步骤条：顶部固定、当前步 `accent` 高亮、完成步 ✓
- 弹窗高度随内容弹簧过渡；未完成时主按钮置灰（`.disabled`）

## 三、设计规范 —— 组件与状态

### 色彩
- 品牌色：`accent #FF7A2F`（行动）/ `primary #34B47C`（成功）/ `blue #4E9BE6`（信息）
- 玻璃上的正文必须用 `--color-text #1c1c28`；muted 只做辅助标签
- 新分类色从令牌 `color.category` 取，禁止临时取色

### 圆角阶梯
`气泡按钮 11px → 控件/列表项 14px → 气泡 16px → 卡片 22px → 大浮层 28px → 胶囊 999px → 抽屉顶角 26px`

### 阴影三件套（所有玻璃组件统一）
```
接触阴影  0 2px 8px  rgba(30,30,60,.06)
扩散阴影  0 12px 32px rgba(30,30,60,.12)
光晕投影  0 24px 64px rgba(78,155,230,.10)   ← 蓝，暖灰底上出现彩色折射
```

### 动效参数（统一，禁止自造曲线）
| 场景 | 曲线 | 时长 |
|------|------|------|
| 弹出/吸附/选中 | `--ease-spring` (.34,1.56,.64,1) | 280–420ms |
| 面板浮现/悬浮过渡 | `--ease-glass` (.22,1,.36,1) | 280–700ms |
| 按压反馈 | linear + scale .96 | 160ms |
| 抽屉关闭 | cubic-bezier(.55,0,.85,.4) 入 | 300ms |

### 组件状态矩阵
每个玻璃组件必须覆盖：`默认 / 按压(scale .96) / 选中(高亮+光环) / 禁用(降透明度) / 深色模式`

### 无障碍（生成时自动套用）
- `prefers-reduced-motion` → 禁用弹簧/拖拽动效（已实现）
- 深色模式 → `[data-theme=dark]` 变量覆盖，禁硬编码白底（v3.4 教训：108 条覆盖规则）
- 正文对比度：玻璃上的文字禁止用 muted 色

## 四、使用方式（AI 生成流程）

1. **模糊需求** → 查「术语库」翻译成术语组合（例："高级的底部弹窗" → T2 底部抽屉 + 阻尼拖拽 + 全屏吸附 + 边缘光）
2. **点名模版** → 从「模版墙」选 T1–T6，预设自动带入
3. **落地实现** → 引用 `design-tokens.json` 的令牌值，禁止自造颜色/曲线/圆角
4. **验收检查** → 状态矩阵五态齐全？深色模式覆盖？reduced-motion 降级？
