# 🗺️ 四川文轩职业学院（遂宁校区）校园导览地图

基于**《遂宁校区导视图》线稿原图**制作的校园地图 Web 应用，手机端优先。

![底图](assets/campus-map.jpg)

## ✨ 功能

- 🔍 **建筑搜索** — 48 个地点（1~8号教学/实训楼、学生宿舍13~38#、教师公寓、三食堂、篮球馆、足球场…）
- 🧭 **路线导航** — Dijkstra 最短路径，沿校内路网绘制，显示距离与步行时间
- 🏷️ **分类筛选** — 校门 / 教学楼 / 宿舍 / 食堂 / 运动场 / 广场 / 书院 / 服务
- 📱 **双视野模式** — 竖屏默认「浏览」（地图满屏、可拖动，右上角小地图随时看全貌），
  一键切换「全览」完整查看官方导视图；横屏/桌面自动完整显示
- 📍 **POI 圆点** — 分类色圆点常显（重点地点大号+图标），点击/搜索/筛选时弹出名称牌
- ⭐ **收藏 / 足迹 / 自定义地标** — localStorage 本地持久化

## 🛠️ 技术栈

| 组件 | 说明 |
|------|------|
| Leaflet.js 1.9.4 | 地图引擎（CRS.Simple 平面坐标系，零 API Key） |
| 原生 HTML/CSS/JS | 零构建、零依赖 |
| Dijkstra | 道路网络无向图最短路径 |

## 🚀 本地运行

```bash
python -m http.server 8402
# 打开 http://127.0.0.1:8402
```

## 📁 项目结构

```
campus-map/
├── index.html              # 页面骨架
├── css/style.css           # 全部样式
├── js/campus-data.js       # 48 个 POI + 路网（50单位网格逐栋人工校准，1单位≈1米）
├── js/app.js               # 地图/标记/搜索/导航/视野模式
├── js/appshell.js          # App 壳（Tab/个人中心/设置/我的位置）
├── assets/campus-map.jpg   # 旧版线稿导视图（4300×2250，校准基准帧）
└── tools/
    ├── official_poster_src.jpg  # 底图源文件
    └── build_basemap.py         # 底图构建脚本
```

## 📐 坐标系

平面 1000×500，整幅导视图映射：`data_x = px·1000/1781`，`data_y = py·500/883`。
POI 坐标来自对官方图注记（红圆编号牌/色块）的程序化检测 + 人工核对。
